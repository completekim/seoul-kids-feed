# seoul-kids-feed

서울 열린데이터광장의 공개 API 두 개에서 **미취학 아이와 갈 수 있는 것**만 골라 `data/feed.json` 하나로 만든다. 개인용 축제 알림 메일이 이 파일을 읽는다.

- 🎟 `yeyak` — 서울시 공공서비스예약(문화체험·교육강좌) 중 지금 접수 중인 아이·가족 프로그램
- 🎠 `kidscafe` — 서울형 키즈카페 지점 중 가까운 5곳
- 🎭 `culture` — 서울 문화포털 문화행사 중 앞으로 45일 안에 볼 수 있는 아이·가족 행사

거리는 스타필드 시티 위례에서 잰 직선거리, 25 km 안만. GitHub Actions가 하루 두 번(05:17·17:17 KST) 갱신한다. 인증키는 저장소 시크릿 `SEOUL_API_KEY`.

데이터 출처: 서울 열린데이터광장 (data.seoul.go.kr), 공공누리.
